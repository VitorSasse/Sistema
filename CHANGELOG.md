# Changelog

Todas as alteracoes relevantes do sistema devem ser registradas neste arquivo.

O formato recomendado e:

```text
## v1.1.0 - 2026-07-01

- Descricao curta da alteracao.
- Correcoes importantes.
- Observacoes de deploy ou rollback.
```

## v1.0.0 - 2026-07-01

- Criada estrutura inicial de versionamento, backup e rollback por Git.
- Criados documentos de fluxo Git, rollback e controle de versao.
- Adicionados scripts auxiliares para tags, rollback e changelog.
