# Versao do sistema

Versao atual: v1.0.0

Esta versao representa o estado estavel inicial a partir da criacao do fluxo de backup e rollback por Git.

## Como atualizar

1. Atualize este arquivo com a nova versao.
2. Atualize o `CHANGELOG.md`.
3. Faca commit na branch de release.
4. Crie a tag com `npm run version:create -- v1.1.0 "Descricao da versao"`.
5. Publique a tag com `git push origin v1.1.0`.
